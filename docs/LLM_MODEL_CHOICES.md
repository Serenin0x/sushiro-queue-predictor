## 按本项目计算费用

费用公式为 `调用数 × (输入token×输入单价 + 全部计费输出token×输出单价) / 1,000,000`。例如每次1000输入、200计费输出，2万次／月，假设全部未命中缓存：DS全空闲36元、全高峰72元；Qwen3.7短输入档7.2元；Qwen3.8-Flash26.8元；Qwen3.8-27B108元。这些是按表价推算的示例，不是实际用量或含服务器的总账单；长思考、额外调用、地域与价格调整会改变结果。

每店共享一次公共分析，再在本地结合每个人的私人号码和时长，避免按用户倍增调用。30秒持续一整天为2880次／店／天；只在需要时进入高频，绝不能把上面的2万次示例误当全国30秒监控月预算。提前配置 token／请求／金额上限，按实际usage记账，缓存命中不能预先保证。

## 初步建议与选型证据

先保留DeepSeek为优先，增加Qwen3.7-Flash低费用对照和Qwen3.8-Flash新版对照；开源部署的具体候选是Qwen3.8-27B。API部署可由普通采集服务器调用；开放权重自己推理仍需内存、算力和运维，不能把权重免费等同服务器免费。本轮没有安装权重或租用GPU。

用固定公共输入组实测短JSON有效率、字段／算术一致性、超时、每次总成本及p50/p95完成时间；首次token速度不能代替完整结果时间。再用相同真实号单时间切分检验中位误差、较早叫号风险、区间和冷启动；达到收益再启用数值影响。需要绑定实际模型版本、提示词版本和价格日期，监控供应商别名变化。[实时模型契约](REALTIME_PREDICTION_MODEL.md)

rc47已增加[固定官方接口的受限适配器](DEEPSEEK_ADAPTER.md)，默认无网络，只有显式私有预算和独立密钥才可请求；同店公共输入去重、不自动重试，实际usage与预留分别保存。当前仍没有实际付费调用，价格配置是操作方给定估算上界，不能当账单认证。
