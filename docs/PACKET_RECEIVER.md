# 有界本机数据包接收服务

`packet-receiver`提供一次短时本机HTTP接收，连接“接收、格式验证、事务归档、返回确认”。它只监听`127.0.0.1`，不绑定公网，不查询寿司郎、不更新查询凭证。当前不是已部署服务器或永久服务。

## 启动

```sh
sushiwait packet-receiver --db "$PRIVATE_INGEST/archive.sqlite3" \
  --receiver-token-file "$PRIVATE_INGEST/receiver.token" \
  --seconds 30 --max-requests 4 --port 0
```

使用者明确准备已有本人0700目录及0600/0400单链接接收口令文件。口令独立于寿司郎账号和查询上下文：32–128个ASCII字母/数字/下划线/连字符，可带一行结尾。服务不生成、输出或上传口令；不能拿HAR或查询配置代替此文件。归档库不能与口令同路径。

端口0由系统选择空闲端口，终端只报告实际端口、时间/连接上限及聚合结果。一次1–60秒、最多1–100个连接，拒绝的连接也计入；独立定时器关闭监听及正在读取的连接，慢请求不能保持网络窗口。磁盘事务、系统调度与清理耗时另受运行环境影响，时间参数不构成全部进程操作的硬实时保证。

## 接收约定

固定`POST /v1/public-observations`，无查询参数；必须有且仅有一个`Authorization: Bearer …`、对应`127.0.0.1:端口`的Host、规范Content-Length及application/json。只支持明确长度、不超过4MiB的正文；拒绝重复关键头、Transfer-Encoding、Expect、Origin和Cookie。每个连接完成后关闭；没有CORS、浏览器登录或额外路由。标准HTTP解析器仍有自己的头部上限，4MiB只指正文。

正文遵循[公共字段包](PUBLIC_PACKETS.md)与[归档约定](PACKET_ARCHIVE.md)，拒绝空包、未知字段/重键、未来时间、坏校验等；校验前不创建归档。相同观测/完整内容重复不新增，同标识不同内容整批409/保留旧数据，提交或持久性不确定返回503且没有成功确认。错误只含固定类别，不回显请求、口令或原始异常；默认访问日志关闭。

## 确认及重试边界

rc21的200确认使用schema2及独立接收口令HMAC-SHA256（规范JSON排除HMAC字段），包含规范整包SHA、每条观测ID与内容SHA、本机归档提交/持久性及新增/重复数量。只有整批持久化成功后返回；不包含查询头或个人号单。`receiver_context=loopback_development`及`remote_deployment_verified=false`明确当前上下文，来源新鲜度unknown/真实性未认证/真实标签0/ETA不可用。

网络响应丢失时，资料可能已写入；调用方保留原包并原样重试，接收器依观测ID识别重复。一次200也不能替代调用方核对包与各观测校验值、可靠保存确认、可信目的地/TLS或上传游标。[本机投递工具](PACKET_DELIVERY.md)已实现对应校验、私有确认保存及离线重开；仍没有远程上传器、确认后的自动删除/保留策略、远程部署、长期服务、备份或生产限流验收。本机HTTP仅用于开发，远程传递须另行实现和验收安全传输。

检查涵盖真实本机HTTP往返、身份/格式拒绝、冲突、提交不确定、已提交丢响应后的原样重试、空闲及部分头/正文截止。合成检查、独立安装与真实两页发送的证据分别记在[PROJECT_HANDOVER](PROJECT_HANDOVER.md)。
