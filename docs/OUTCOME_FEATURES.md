# 私有排队经历与门店观测对齐

开发候选 rc44 提供 `outcome-feature-export`：将审核过的本人排队经历，与重建预测时刻之前已经接收的匿名门店观测对齐，生成私有研究文件。它没有拟合模型，也不提供已校准 ETA。真实性认证、历史请求上下文认证和可训练标签仍为零；软件测试使用合成资料。

## 输入与边界

显式指定三份独立、已停止写入的数据库：首次接收结果库、审核库、匿名门店观测库。三个库须位于不同私有目录，输出另放一个私有目录；目录 0700、文件 0600。正在运行的采集库持有独占锁，本工具拒绝读取。不要为了导出而中断当前有限采集，也不要复制正在变化的库；等待自然结束或使用已封存的独立窗口。

计划恰好包含以下字段。例子仅说明结构，日期截止须由操作者明确选择，不表示存在对应真实结果：

```json
{
  "schema_version": 1,
  "as_of": "2026-10-08T00:00:00+08:00",
  "data_origin": "synthetic",
  "queue_data_origin": "synthetic",
  "api_profile": "miniapp_gateway",
  "store_id": "900001",
  "elapsed_seconds": [0, 300],
  "max_cases": 100,
  "window_seconds": 120,
  "max_gap_seconds": 90
}
```

`data_origin` 为 `synthetic` 时，队列来源声明也必须为 `synthetic`；人工结果 `self_reported` 配 `live`。这只是操作者声明，不能认证运输来源或真实事件。`api_profile` 适用于结果库，匿名队列始终保持独立 `crm_remote_v1_1` 来源，不被转换成微信接口数据。

```sh
sushiwait outcome-feature-export \
  --source-db private-outcomes/received.sqlite3 \
  --reviews-db private-reviews/reviews.sqlite3 \
  --remote-db sealed-observations/remote.sqlite3 \
  --input private-features/plan.json \
  --output private-features/dataset.json
```

输出只允许新文件；已有文件不会被覆盖。终端仅打印安全数量和持久化状态。完整文件包含个人经历的关联标识、门店和精确时间，必须保留本机私有，不能公开提交或传给大语言模型。若提交完成但持久化确认失败，返回 `committed=true`、失败退出码；先核对文件，不能盲目重写或删掉它。

## 怎样保持时间边界

1. 按评价截止选择已接收的结果修订及对应审核，后来的修订和审核不能替代早先证据。
2. 用取号时间上界加指定经过秒数重建预测时刻，只保留严格早于叫号时间下界的候选；不确定时间保留上下界，不取中点。
3. 完整扫描指定库的有界历史，再按门店、整对查询完成时刻和本机首次接收时刻筛选。即使响应声称很早，今天才接收的旧数据也不能进入过去的特征。整对查询未完成时，不提前使用其中第一条。
4. 集合变化及原始计数分别计算；失败、缺口、run 切换、逆序和缺失接收信息打断可比链。只有窗口内的合法最近响应提供原值，同时显示年龄与 `stale` 等状态；无可用资料保留缺失，不填零。

每份结果包含静态队列/人数/桌型、经过时间、当时可知的日期分类、五个有限展示数组的长度及不同字符串数量、未知单位原始计数、独立窗口变化和覆盖统计。展示号码作为不透明字符串处理，号码差不是前方桌数；数组增删不是完整叫号记录，真实过号率保持 `null`。

预测特征、获准队列输入和完整研究数据集分别保存 SHA-256。有效未来记录不改变早先行的特征或指纹；完整扫描的审计数量单独保存，不能送入模型。任何坏行使整次导出失败，不能跳过后把不完整资料称为完整历史。

每个库最多扫描 10,000 条修订/观测，匿名库还有 32 MiB 总负载上限；最多 100 行候选、16 个递增经过时间、2 MiB 私有输出。超限拒绝，不截成“最新若干行”冒充历史完整。可显式降低 `--max-revisions`、`--max-observations`；更大数据规模需以后独立设计封存和分区读取。

## 尚未认证的部分

本机首次接收读取早于实际数据库提交，不是外部时间存证或历史持久化证明。人数和桌型从事后结果重建，不代表当时真实请求输入；目标上下文及真实预测日志仍未认证。匿名响应门店身份、源刷新时刻、计数单位保持未知。人工审核声明与事件真实性分开，`training_eligible=false`、`verified_training_labels=0`、`eta_available=false`、`model_fitted=false`。

后续要先取得正常真实取号和叫号证据、认证字段及记录实际预测输入，再按时间和独立排队过程切分训练/验证/校准资料。分位数模型、日期分组误差、LLM 外部事实作用和防过号效果均须独立回测。这份文件准备研究输入，不能代替这些验收。
