# 公共字段包的格式校验与本机归档

rc18新增`packet-check`和`packet-archive`，验证rc17允许字段包，并将记录事务保存到一个独立私有归档库。相同观测ID与相同内容重复导入只保留一份；同ID不同内容会拒绝整批。当前是本机归档及未来接收器的协议准备，没有HTTP服务、上传、远程身份认证、生产服务器或服务端确认。

## 用法

```sh
sushiwait packet-check --input "$PRIVATE_EXPORT/page-001.json"
sushiwait packet-archive --input "$PRIVATE_EXPORT/page-001.json" \
  --db "$PRIVATE_ARCHIVE/public-records.sqlite3"
```

使用者明确准备已有本人0700目录；JSON为本人单链接0400或0600常规文件，最多4MiB。归档库必须为单链接0600常规文件，不能使用快照DB2或个人结果库。没有自动搜索、目录创建、权限修改、SQLite迁移或未知格式回退。检查失败不会由CLI创建归档库，输入与输出路径相同立即拒绝。

`packet-check`只输出数量、内容哈希和校验状态，不创建数据库。`packet-archive`额外输出新增/重复条数与本机提交状态；不输出号码、记录正文、原始异常、文件路径或个人信息。两者均不查询寿司郎、不读取凭证、不调用原生应用或子进程。

## 校验与资料语义

允许字段、范围和标识规则见[PUBLIC_PACKETS.md](PUBLIC_PACKETS.md)。接收检查使用精确的顶层/记录/展示/时间字段集合，未知字段整包拒绝，不能把任意JSON保存到归档。版本必须是整数1，布尔值不能冒充版本或数量；资料范围为1–3规范门店ID、固定profile、live/fixture/synthetic且每条记录一致。

时间为导出器生成的规范UTC表示，包含六位微秒和Z。资料截止时间不能晚于本次CLI的系统时钟，记录不能晚于包的截止时间；HTTP开始/接收与本机preflight时间语义独立检查。未来/逆序、重复观测ID、矛盾范围、未知有效状态或超出窄格式的展示号、非法失败分类、非有限JSON数、重复JSON键、过大正文均拒绝。缺失/null/invalid/unknown及未知单位保留，展示号不改成游标或人数。

每条UUID5标识与规范内容SHA必须符合格式并匹配。校验能发现传输或保存改动，**不能证明数据是官方产生、未被有意重算，或源信息刚刚刷新**。导入始终保留`source_claims_verified=false`、`source_freshness=unknown`、`server_received=false`、`verified_training_labels=0`、`eta_available=false`；不能通过输入的true/数量覆盖这些语义。

## 独立归档库

归档schema1与既有快照DB2/个人结果schema1分别使用不同表和格式，不能因为版本数字相同就混用。创建/打开时核对明确表结构、未知对象和journal模式；使用本人目录的非阻塞协作锁、文件身份与权限复核，同一协作目录中的第二个写者会停止。不能把协作锁当作对恶意同账号进程的完整隔离。

归档记录包含允许字段的规范正文、观测ID/内容哈希、门店/profile/origin、记录时间与**本机第一次保存时间**。本机保存时间不替代源更新时间。一次最多1000条，以SQLite单个事务处理：相同ID和完整规范内容保持原记录/首次保存时间，不新增；出现内容冲突则回滚整页，包括本页此前尝试插入的新记录，保留原值，输出固定冲突类别。

提交结果明确区分：

- `not_started`：本批没有进入提交步骤；格式、锁、冲突或插入失败等不会被当作成功。
- `committed`：SQLite提交已返回；提交后的目录确认失败仍报告已提交，不回退或覆盖记录。
- `unknown`：已尝试提交但未获得可靠返回；不能解释为确定未写入，需重新只读核对后再决定操作。

正常完成另显示`durability_confirmed=true`；失败显示false。本工具不会自动重试提交异常、不删除源包，不记录或推进上传游标。本机提交成功不等于服务端收到，更不等于远程用户已经收到通知。
