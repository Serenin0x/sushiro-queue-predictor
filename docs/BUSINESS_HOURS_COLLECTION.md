## 运行契约

- 配置文件为[默认营业表](../config/default-business-hours.json)，显式`--business-hours-file`才启用；省略参数的历史命令仍保持原协议，不能拿旧24小时命令当新营业自动化。
- 配置严格有界、拒绝重复JSON键／非法时刻／区间重叠，规则嵌入原任务；修改外部文件不即时更改运行任务，恢复必须与原规则一致。初次部署可以复制并填写门店或日期覆盖，再创建新实验；不要编辑旧检查点绕过冲突。
- 每次实际GET之前重新核对窗口、任务截止和停止请求。第一响应跨闭店时保存第一条结果，第二GET无实际网络，记录business_window_closed；scheduled_pause_slots独立计数，不能算完整成功或查询失败，不补零。
- 闭店只等待，不消耗新的查询槽位；下一窗口自动接续。已开始的响应可以在闭店后收到，不伪称闭店前接收；极小的本机检查与传输调用间隔不表示上游事件秒级认证。
- 保留一个原期限和累计预算；暂停槽位消耗一组预算，实际GET分别记。跨日、分段和进程恢复不重新发未知请求，不补采过去缺口，不恢复失败终态。单写者仍1–3店，可通过只读观察台汇合多批次。
- 当前HTTP／协议首个真实失败仍停止该任务，不自动重试网络查询。Compose的on-failure:3只保护进程退出，不能修复已经失败的持久任务，也不是永久每日调度。持续24／72小时来源质量、故障恢复控制器、监控通知和备份恢复仍需验收；此阶段是有界试采。

## 本机命令

状态目录必须专用0700、计划0600；明确选择新的实验目录，旧无营业门控任务与四个已停止数据卷保持。

```sh
sushiwait remote-campaign-serve \
  --root /absolute/private/new-campaign \
  --plan-file /absolute/private/plans.json \
  --business-hours-file /absolute/path/config/default-business-hours.json \
  --store-id 3014 --store-id 3004 --store-id 2009 \
  --base-interval 60 --duration 172800 --window-duration 86400 \
  --max-pairs 4500 --resume-if-present --port 8765
```

plans文件可以是`{"schema_version":1,"plans":[]}`。上述48小时／4500组9000GET是一个批次的总边界；三个门店共用预算，不是每店4500组。运行中可沿既有计划更新接口声明近时段60／30秒需求，但营业外仍不查询。未声明实际提醒或个人计划时，不造用餐目标触发加速。

## Linux部署

使用新的项目名创建独立卷，避免让旧任务配置冲突。Dockerfile包含默认营业表，基本镜像无GPU、大模型或微信依赖；统计服务只发布本机回环，远程通过本人SSH通道查看。

```sh
docker compose -p sushiwait-business \
  -f deploy/compose.yaml -f deploy/compose.business-hours.yaml up -d --build
```

上例只启动三试点、48小时有界采集。结束后的图表仍可查看保存副本，不会自动新增无界任务；不得通过反复删卷重开续预算。四批十二店本机试验与云端部署分别记录，未购买／部署生产主机。低价年付选择及续费要求见[服务器租用](SERVER_RENTAL_GUIDE.md)。

## 每日统计出口

- `/statistics`：仅浅色简单月历、日期／门店筛选、号码位置散点、原始数量与展示集合变化速度、明细。`/monitor`继续显示最近360组。
- `/api/v1/days`：当前批次每日摘要；观察台汇合各批次，保留configured_store_ids／cohort_id和不可读取门店列表。读取失败不是零数据。
- `/api/v1/stores/{store}/days`及`/days/YYYY-MM-DD`：单店摘要和当天曲线副本。HTTP只读线程内副本，不开活库、不调用来源；所属写者从自己的已提交行恢复投影。
- 完整原始五数组／重复／后缀保存在私有SQLite；图表每数组只绘前三个展示位置，每店每日期最多2048组，响应最大2MiB，有截断显式标记。每日摘要覆盖全部已提交行；私有SQLite保留全记录，图表不是完整源事件。
- 日期使用队列请求开始的北京时间；数量点使用自己的响应时刻，两个查询不是同一瞬间。跨日期、失败、run或长缺口不算展示周转速度；有限展示最大值和差值不是全局叫号游标。
- 日历当前颜色表示背景采样格覆盖，至少80%才标绿色；缺少任一配置门店的全店日不可标整体足覆盖。覆盖分母根据声明营业表及背景频率，快速轮询不重复增加同一格；不是正式连续覆盖验收。人流量热度阈值需积累可比集合和有效指标以后校准，实际叫号人数／真实过号率保留unknown。

当前日期投影和原库范围属于同一有界实验；旧实验另保留，没有悄悄混入新预算／成绩。每日文件导出／跨实验统一索引、永久故障控制、旧实验在此新日历直接浏览及云端连续验收仍待后续。
