持久诊断确认yyb_reauthorization_required → 邮件专用链接 → 原账号更新二维码 → 本人确认 → 绑定本次故障的签名回执 → 原每日进程选中新恢复账本 → 首组新样本保存后显示恢复。只自动处理明确的原账号重授权；网络错误、寿司郎403和未知确认结果不作为可重复扫码事件。
