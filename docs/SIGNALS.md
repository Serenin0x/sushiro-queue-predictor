# 展示集合的时间窗口分析

`signal-report`只读分析已有公共快照，为后续异常检测和预测特征准备资料。它不发查询、不读取凭证、不修改数据库，不输出原始展示号码或run标识；没有等待时间、真实过号率、告警或重排决策。完整需求与历史见[PROJECT_HANDOVER.md](PROJECT_HANDOVER.md)，字段证据见[FIELD_MAPPING.md](FIELD_MAPPING.md)，数据资格见[DATASET_DESIGN.md](DATASET_DESIGN.md)。

## 使用方法

明确指定已有数据库、门店、来源、接口配置和分析当时：

```sh
PYTHONPATH=src python3 -m sushiwait signal-report \
  --db "$SUSHIWAIT_SNAPSHOT_DB" --store-id 3014 \
  --api-profile miniapp_gateway --data-origin live \
  --as-of 2026-10-04T18:04:20+08:00 \
  --window-seconds 300 --max-gap-seconds 90 --sample-limit 10000
```

示例时间是既有采集的历史回放，不表示当前仍有实时数据。`as-of`必须带秒和显式时区；窗口30–3600秒，默认120；最大相邻间隔1–3600秒，默认90；扫描1–10000条，默认10000。窗口及缺口阈值是分析参数，不自动改变采集节奏，也不是已校准的门店规则。

仅按store_id、data_origin、api_profile隔离读取。已有DB1通过只读legacy视图使用，不迁移、不混入gateway数据；缺失数据库返回固定错误，不创建新库。success/exit0表示分析完成，可能没有可用观测，不能仅凭退出码启用预测。

## 指标含义

每类队列分别统计可比较相邻对、展示集合变化、展示数组顺序/重复变化、新出现/消失的不同字符串数量，以及这些相邻对实际覆盖的秒数。号码作为不透明字符串处理：A001、B001、后缀、重置、重复和顺序都不变成数字游标；没有跨队列合并。

`removed_labels_per_observed_minute = 消失的不同展示标签总数 × 60 / 可比较对覆盖秒数`，新增标签同理。没有可比较对时为null；已观察空数组且有有效相邻对时可以为0。`observed_fraction_of_window`说明可比较对覆盖窗口的比例；分母不是所有请求间隔，也不是实际队列事件时间。消失、再次出现的同一标签可能被重复观察到变化，不等于不同顾客人数。

`groupQueuesCount`另统计有效相邻对的原值差之和，单位继续unknown；不是跨缺口的首尾差或入座/弃号数。没有有效相邻值时保持null，bool、异常大值及缺失不补零。

窗口平均分为前后两半，只有两端都在同一半的相邻对才参加该半统计，跨中点的对仅计入整个窗口。每半至少两对才比较未舍入的消失标签速率，输出higher/lower/equal和比值；前半为0时比值null、status=previous_zero，不输出无穷大。两分钟窗口在30秒采样下常不足两半样本，因此可能insufficient_pairs；可明确选择更长窗口。方向只是数值比较，没有显著性、校准阈值或真实加速原因判断。

## 时间与质量边界

- 只使用窗口内、接收时刻不晚于as-of的观测。请求开始/接收时间、数据库记录时间必须匹配且顺序有效；字段及门店身份复核后才比较。
- 失败、坏JSON、无效时间/身份、run切换、超过最大间隔会断链。缺失/无效队列字段只中断该队列的相邻比较。时间逆序的成功记录不作新锚点，避免重叠秒数重复累计。
- availability区分近期观测、陈旧、没有观测、末尾中断和未知。陈旧或中断时不提供“当前”半窗比较；近期响应也不代表门店源刚更新，upstream_freshness始终unknown。
- 扫描先取本组最新的有限sample ID，再按时间过滤。truncated表示可能遗漏更早的可用资料；不是完整as-of历史重建。future/older/invalid等扫描诊断不应作为模型输入，训练导出仍未实现。
- 计数和流式扫描在同一个显式只读事务内取得一致视图；原始payload在SQL层限2MiB，最多保留相邻快照，不加载全部正文。事务行为依据[SQLite官方说明](https://www.sqlite.org/lang_transaction.html)，不使用写事务或迁移。
- 附as-of日期分类及来源版本，表示该时刻的日期身份，不把整个跨日窗口归成同一日期，也不声称项目当年已经拥有生产特征日志。

输出只含白名单统计、公开门店身份及分析时间，不含原号、凭证或个人结果。精确时间和门店仍可反映分析意图，分享时按实际用途处理；此工具不读取私有结果库。
