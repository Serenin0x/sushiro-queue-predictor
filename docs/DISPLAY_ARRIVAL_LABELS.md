2026-10-14 R71 / E0511。用户明确接受用页面位置近似叫号：输入门店、队列、本人号码和取号时间，号码进入前两位，或者三个展示号码都已越过本人号码，即得到本项目的到号结果。**这个结果可以用于初版预测训练和回测；取得现场精确叫号时间不再是推进预测的前置条件。**

## 判定规则

| 当前展示 | 本人号码150的结果 | 保存类型 |
| --- | --- | --- |
| 150、151、155 | 已到号，第1位 | `display_top_two` |
| 148、150、155 | 已到号，第2位 | `display_top_two` |
| 148、149、150 | 即将到号，尚不判到号 | `display_third` |
| 151、153、158 | 推定已到号，即使未签到或从未出现 | `display_all_three_passed` |
| 149、153、158 | 尚未判到号，不能只看最大号码 | `not_reached` |
| 空列表、请求失败、只有1–2个更大的号 | 暂无足够的越号证据 | 保留缺失／等待 |

保留原展示顺序，不排序后重算第1、2位。三个号码必须全部严格大于本人号码，不能与预约队列混用；数字前导零不影响比较。当前实现接受同店、同一北京时间日期、同一队列的纯数字号；其它前缀和后缀格式不强行比较。已检测的号码回退会暂停该次记录的数字越号推断，但后来直接匹配前两位仍可保留为展示证据。

签到状态按用户提供的真／假／未知保存。未签到但已越号的记录仍有训练价值，不要求本人到现场补签到。若用户填未签到、号码却真实进入前两位，保留展示结果并记录两者不一致，不擅自修改签到状态。

## 时间与数据记录

例如12:00取到150号，12:20看到148、149、150，12:23看到151、153、158：记为推定已到号，首次检测时间12:23，等待区间20–23分钟。前一条是第3位，尚未满足前两位规则。

每个结果保存：策略版本、门店／日期／队列、本人号码、取号时间、声明签到状态、直接出现或越号类型、首次检测时间、原三位号码及观测ID、等待上下界、缺口／回退等质量标记。本人号码和取号时间组合留在私有处理链，不能加进公开门店归档、公共URL或LLM输入。

到号参考时刻采用首次满足条件的响应接收时间。连续相邻采样时，前一条未到号与本条到号之间形成采样区间；这依赖同发号周期和区间内没有未观测回退的假设，不是统计置信区间。3分钟采样可能带来约3分钟的定位宽度，10分钟采样可能约10分钟；接口自身更新时间未知时还存在额外滞后。

第一条已经越号、或检测前遇到失败／空列表／断链／长缺口时仍保留有用结果，使用从取号到检测的较宽区间，不把缺口伪装成精确几分钟。还没到达则保留未完成记录，不填0分钟，也不从训练样本列表中静默删除。

## 模型与评估

主要预测目标改为 `user_defined_queue_arrival`，区分前两位直接出现和三个号码全部越过两个标签类型。最初分别报告这两类误差、签到状态和采样宽度，组合使用时保留类型和质量特征；不凭空指定某类“90%可信”或拍定样本权重。训练、校准与测试仍按完整店日和号单划分，输入只能包含预测当时已获得的观测。终点匹配允许读取未来结果，预测特征不得借用未来。

这个目标代表用户约定的排队进度到达，不证明实际入座、真实爽约或现场叫号。未签到样本可以帮助学习号码推进，但签到后的插回和现场带位仍可能有差异。将来若有现场结果，可另外估计展示参考与实际叫号的偏差，不阻塞当前版本。
