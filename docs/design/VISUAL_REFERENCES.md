# 前端视觉方向、已选参考与大月历原型

日期：2026-10-10。用户已选择图标 D（Lucide）与日历 C（React Aria 的日期布局及圆形选中样式），并要求将月历放大，每天可容纳不同背景色与数字。页面字段、状态和接入仍遵循 [内容规范](CONTENT_SPEC.md) 与 [统计接入说明](STATISTICS_INTEGRATION.md)。

## 用户指定方向

- 浅色、深色两种外观，整体参考 GPT 界面的留白与简洁导航。
- 减少模块及圆角包围的小框，用空间、对齐和必要分隔组织内容。
- 导航按钮平时没有可见边框，悬停和选中时再突出；沿用用户提供的图标栏参考。
- 月历区分节假日、普通工作日和调休工作日；点日期查看当日堂食／预约展示号码、最近每分钟观测和随时间变化的统计。
- 保留 GitHub 内容规范中的功能与流程；界面文字精简，不在边角堆放说明。日期、号码、时间可使用更适合数字的字体。
- 用户先要求网上案例截图，再选定 C／D；随后强调日历每天可能使用不同底色并标数字，因此应作为页面主体，而非紧凑日期选择器。
- 本人继续要求删除“每日观测·组”、休／班解释、底色覆盖解释与0%／100%端点，以及日期详情的日型／覆盖说明；保留格内日期、数字、底色和休／班标记。
- 原系统下拉菜单改为城市→门店两级，两个层级都有“全部”；门店范围覆盖中国大陆，不局限试点三店。

## 已选方向与大月历预览

- 保留 C 的居中月份、左右翻月与圆形选中日期；图标采用 D 的统一线条。放大的日期格使用很小的圆角、无描边，不把每一天做成独立卡片。
- 大月历占主要内容宽度，日期、观测数字与休／班标记分开对齐；底色使用品牌红色的柔和深浅。当前示例编码采集覆盖，数字为观测组数，不编码真实人数。周末由星期列识别，法定节假日与调休单列标记；已按本人要求去掉外围解释及详情覆盖副标题，完整数值／日型仍在无障碍日期标签中。
- 另实际查看 [Minimal Calendar App 的公开预览](https://shadcnexamples.com/demo/minimal-calendar-app)，保存大面积无格线月历截图用于比例参考；它不是 React Aria C 的官方放大版，未复制其付费代码。
- 会话内可交互原型 `sushiwait-month-calendar.html` 已制作：浅／深色、翻月、本月、门店选择、日期详情、两组原顺序号码、号码与首项推进速度曲线、单条原始数量曲线和最近每分钟观测。数量单位保持待确认；示例曲线缺口断线，无数据／未来日期分别展示。
- 初始展示 2026 年 9 月合成资料；休／班来自项目已核对的 2026 全国安排，10 月 10 日是调休工作日。原型的固定年份、示例时间、数据生成器和宿主辅助只用于设计预览，不是实时接入或可直接部署的服务器页面。
- 已在实际浏览器检查 1024、736、320 宽度，月历及当日内容无横向溢出；1024 预览内日期格约 120 × 108，320 预览仍保留七列。实际检查浅深色、翻月、节假日／调休、无观测／未来日期、队列显隐、缺口提示与门店切换；脚本语法通过，页面未出现运行错误。

正式接线由 [原型对应说明](integration/PROTOTYPE_MAPPING.md) 与 [统计接入包](integration/README.md) 继续承接；其中 E0381 记录的原型“双数量曲线”已在本轮预览改为单条，避免形成错误字段期待。设计源与截图留在本次会话，尚未复制进生产静态资源或更新线上界面。

## 城市、门店与全部

- 顶部使用两个默认无框的文字按钮，以箭头连接城市和门店；菜单采用与浅深色一致的浮层，所有可选文字保持可读，当前选项用中性底色及勾选表示。城市、门店都可以搜索，支持键盘箭头／Escape和点外部关闭。
- 选城市后，门店只显示该城市目录；城市变化默认选其“全部”，随后可选一家门店。城市“全部”对应全部大陆目录，右侧门店“全部”作为全局范围显示，不混用跨城门店选择。
- 菜单已加入[现有大陆目录](../../config/mainland-store-catalog.json)的147个唯一店号、31个城市，城市由目录区域字段归属（石家庄三字前缀单列，其余为已核对的两字城市前缀），门店保留目录名称；不再使用只有三家的菜单。目录来自10月3日本人提供的正常官方响应，当前完整性标记仍false，不能宣称已证明今天没有新增大陆门店；此范围不加入香港、日本等门店。
- “全部”月历展示所选范围的合成观测合计，覆盖由观测与预期数量加权；窄屏用紧凑数字，完整值保留在日期无障碍标签中。全部城市的日详情先列31城／147店，再点城市查看其门店，最后进一家店看独立号码与曲线；不同门店号码不合并成同一叫号序列。
- 本轮实际浏览器检查城市／门店搜索、深圳壹方城选择、全国→北京全部22店→西单详情、菜单键盘关闭及空搜索结果；全国147店之和与31城列表一致。1024／736／320宽度菜单和月历均适配，聚合数字无溢出，浅深色菜单文字可读，所列冗余文字不再可见，运行错误0。图表库延后加载，月历及选择器先呈现。

正式接线还需将现有`sw-store`的选择事件适配为新按钮菜单，结合目录区域与公共索引建立城市归属；“全部”月历读取已有索引，不在未选单店时扫描147家明细。原型的目录与合成示例不代表已部署的新统计服务。

## 应用时的约束

2026-10-10后续接线结果：已将选定视觉拆为生产本地HTML／CSS／模块，月历、目录、单店曲线与表格使用真实统计接口；删除两处固定12:30说明、时区改UTC+8，原示例预览保留为历史。新旧页同店同日及浅深色／窄屏检查已完成，部署源码与资源清单见[DS-004](integration/FRONTEND_HANDOFF.md)。主线负责现有地址部署，本设计任务没有更新服务器。既有预测与经历界面由侧栏时钟进入旧页，正式Logo保持。

- 参考用于比较日期布局、选中形状和图标线条；官网外框、图标展示底块不自动进入本产品。
- 蓝／紫参考色不是最终品牌色决定；产品仍以中性色为主，需要强调时使用既定 Logo 的红色风格。
- 节假日标记与数据覆盖标记分别表达，不将采集覆盖着色叫作真实人流热度。
- 展示号码顺序保持原始数组；“每分钟观测”不冒称官方每分钟实际叫号事件。原始数量单位未确认，不能直接标成真实人数。
- 页面刷新与采集频率分开；设计示例注明合成，真实接入读取已有统计节点，不新建来源查询。
- 本轮已完成可交互浅／深色大月历预览；真实统计接线、其他产品流程与部署仍分开推进。线上页面、正式品牌资产和版本号未由本轮设计改动。
