# 大月历原型怎样接真实数据

2026-10-10主线只读设计聊天正在制作的`sushiwait-month-calendar.html`，以下针对当时的元素及函数。原型仍在调整，未作为生产页面发布；此表不复制或冻结独立任务的未完成源码。新页面复用[统计接入包](README.md)，原型的浅深色、大日期格、圆形选中日期及图标仍由设计任务维护。

## 元素与数据对应

| 原型位置 | 实际数据／接线 |
| --- | --- |
| `sw-store` | 从月历响应`configured_store_ids`和`store_names`建立选项，替代仅三家店的硬编码；选择值必须仍在目录里 |
| `sw-month-title`、`sw-days` | 选定月份＋`calendarCells`；将`dayData`的随机覆盖和观测数替换成真实摘要，null显示暂无／待加载，不补0 |
| `sw-selected-kind` | 年份明确的日期类型＋所选日摘要；2026日型资料可本地打包，未知年份待核 |
| `sw-queue-dine` | `latestQueue(detail,'mixedQueue')`，原顺序前三位字符串；失败或陈旧暂停当前提示 |
| `sw-queue-reservation` | `latestQueue(detail,'reservationQueue')`；两队列来自同一次队列响应，各保留原文 |
| 号码下方`.sw-detail-note` | 使用真实`queue_received_at`及历史／陈旧状态，替代写死的12:30；不得把当前看历史日说成实时 |
| `sw-number-plot` | 两队列的`chartSeries(...).reference`分别分段，横轴为真实响应时间，保留各自号码轴；不用合成的0–30分钟位置 |
| `sw-speed-plot` | 推荐使用两队列各自`turnover`的独立点／柱，单位展示号码变化／分钟；同时更新aria说明，不与首位位置差混算 |
| `sw-count-plot` | **只有一条**`rawCount`及`count_received_at`，单位未知；现有接口没有堂食、预约分别的数量，不接原型中的两条合成数量曲线 |
| `sw-records` | 从`detail.points`取最近观测，时间用`queue_received_at`，两组原数组直接展示；有效空数组与查询失败分开，不调用`queueArray`补造后两位 |
| `sw-day-empty`、`sw-day-content` | 由controller的加载／失败／部分状态及真实空投影决定；读取失败不能显示“这一天暂无观测” |
| `sw-status` | 加载／失败状态除无障碍提示外，也须有可见的简短提示；保留正文精简但不要把必要状态藏起来 |
| `sw-demo`及合成说明 | 原型保持示例标记；真实接线后标数据更新时间。若保留演示模式，显式选择并标合成，不在真实API失败时暗中回退示例 |

## 替换函数

`dayData`、`buildSamples`和`queueArray`只是示例生成器，正式数据模式删除其回退路径。月历直接用`calendarCells`，当天图表与表格使用同一份`state.detail`，避免表格和图表读不同批数据。

原型的`current`、`key`和`dayCount`锁定2026；接线时用`shanghaiDate()`与所选月份，支持真实月末、闰月和跨年。点击上／下个月要同时更新月份、日期与controller选择，不能留着上一月的detail。只有队列显隐与外观切换只在页面内发生，不新增统计请求。

原型速度按“第一位参考位置差÷分钟”合成。接线推荐的`turnover`则为“从展示集合中移出的不同号码数÷观测分钟”，二者语义不同；更新标题、轴名、悬停说明和aria一起完成。如果未来保留首位位置推进图，单独命名、仅在同周期正向可比片段计算，不称真实桌数或过号率。

原型悬停可对合成曲线插值。正式号码和数量悬停应找实际观测点并显示其响应时间，直接展示原字符串／原数值；不能生成12.4号或声称12:03:17是实际采样时刻。曲线线段可以表达趋势，悬停数值要与表格原点对应。缺口和倒退不跨段查找伪连续数据。

## 从可视化原型变成服务器网页

目前原型含内联style／script、CDN D3与可视化宿主桥接。现有网关严格内容策略不直接支持这份嵌入式HTML；正式上线需拆成本地HTML、CSS、JS模块，固定资源清单与正确MIME。若保留D3／Lucide，将确切版本及许可的本地文件纳入发布，避免运行时外网CDN；本次没有复制第三方库、放宽内容策略或开放额外端口。

`window.openai`、`Tweak`与widget状态只用于设计预览，服务器网页不依赖这些宿主。正式界面可本地保存公开选择与主题；个人号码／取号时间未来仍按私人数据规范处理，不放URL、公共接口或模型可见状态。

由主线按资源清单同源安装到固定`/statistics`，保留旧显示层可回退及已有API。设计任务交付完整源码后，对同店同日逐项核对颜色覆盖、前三位、时间、表格／图点、缺口／失败、加载与手机布局；未接功能不显示可执行按钮。此交接不重建采集任务，也不把“已看过原型”当“已接线或上线”。
