# 实时模型的时间顺序对照回测

rc54新增`realtime-backtest`，在同一批排队经历、同一批重建预测时刻上，对比纯历史、纯实时邻域和固定先验融合。输出实际区间误差、预测区间宽度、确认／可能覆盖，以及无法预测或无法评分的数量。它不选择“冠军”、不调参、不调用AI供应商，也不将研究结果升级成真实已校准ETA。

## 当时能知道什么

三个显式私有闲置库分别保存首次接收结果、审核声明和封存门店观测。先按评估截止选择已接收的叫号声明；每个目标的取号时间上界加配置已等秒数，构成待回放时刻。该时刻必须严格早于叫号区间下界，否则不属于“确定尚未叫号”的条件样本。

每次训练重新使用该预测时刻以前已接收的结果与审核，并排除目标episode的全部观测。队列使用完整有界扫描，响应完整对以及本机首次接收均须已发生；晚补的旧响应、之后收到的结果、之后才完成的审核不会倒灌到更早时刻。缺少首次接收的旧队列不能补造接收时间。

当前协变量来自同一套[经历与观测对齐](OUTCOME_FEATURES.md)，明确保持`saved_history`、`collector_running=false`。模型的独立封存回放路径仅在回放时钟等于预测时刻、AI混合为0且上述来源状态成立时允许拟合。实时命令和自动追踪仍走默认实时路径，保存历史、过时或停采资料继续不能当作当前实时输入。

结果首次接收发生在提交以前，只是本地可用时间的下界，没有独立时间或持久可用认证。目标人数、队列、取号时刻和“尚未叫号”均由已审核结果事后重建，不能称当时真实用户输入或线上预测日志。

## 三份预测公平地比较

| 变体 | 分布来源 | 数据不足时 |
| --- | --- | --- |
| `history_only` | 当时可用的同店、队列、人数桌型与日期分组等待分布 | 保留无法预测 |
| `realtime_only` | 相近已等时长和展示变化的独立经历邻域 | 保留无法预测，不借历史冒充实时拟合 |
| `prior_fusion` | 原实时模型的历史／实时完整CDF与调用者声明的固定权重 | 遵循原模型历史回退规则，并记录实时是否真正拟合 |

若实时拟合的完整CDF和历史完全相同，它作为相同的对照保留，不能人为制造第二种快慢情景。新取号评估总等待；已排队评估条件剩余，直接剩余不再扣一次已等时长。

参数事先写进输入计划，没有按测试结果选邻居数、日期退层、权重或较好的变体。本工具本身不调参；调用者反复修改参数并查看同一测试集，仍可能造成评估选择偏差，不能据输出的`parameters_tuned_on_test_outcomes=false`声称外部过程也没有调参。真实调优应再留独立的未来测试资料。

## 误差和不确定性

每份预测完整保留p10、p50和p90分位包络。点预测使用p50包络中点的确定决策规则；它没有把叫号标签区间中点当成训练真值。评估区间使用p10下界到p90上界，继续按[区间评估](INTERVAL_EVALUATION.md)计算绝对误差界、确认覆盖和可能覆盖。这个区间不是经过校准的80%保证。

未知上界保持未知，无法用有限区间评分时保留`unbounded_quantile_envelope`。缺资料保留`no_eligible_distribution`，不会只展示有预测的成功案例。各模型单独统计可用率，成对比较只用两者均有有限评分的同一批案例，同时显示该批历史与对照的覆盖、宽度和误差；模型失败或冷启动不被静默删除。

成对误差变化为`|对照点-T|-|历史点-T|`。对同一个未知实际叫号T，在其观察区间内计算上下界；该分段线性式的极值出现在区间端点或落入区间的两预测点，使用整数微秒精确计算，再汇总到秒。负值表示对照误差更低。分别计数确定改善、确定变差、相同或无法判断；不把两份误差当作独立真值来相减，也不报告未计算的统计显著性。

按已等时长分别报告，同一组每episode最多一次；不同已等时长仍是同一人的重复更新，不能合并成更多独立用户。尚未加入聚类置信区间、右删失、取消竞争风险、理想取号全网格评估或真正供应商AI的历史对照。

## 私有使用方法

```sh
sushiwait realtime-backtest \
  --source-db private-source/outcomes.sqlite3 \
  --reviews-db private-reviews/reviews.sqlite3 \
  --remote-db private-sealed/remote.sqlite3 \
  --input private-output/replay-plan.json \
  --output private-output/replay-result.json
```

输入实例（下述是假定已存在的合成资料，不用于访问真实门店）：

```json
{
  "schema_version": 1,
  "as_of": "2026-10-06T06:00:00Z",
  "data_origin": "synthetic",
  "queue_data_origin": "synthetic",
  "api_profile": "miniapp_gateway",
  "store_id": "900001",
  "elapsed_seconds": [0, 300, 600],
  "max_cases": 100,
  "window_seconds": 1800,
  "max_gap_seconds": 360,
  "minimum_samples": 8,
  "neighbors": 20,
  "minimum_episodes": 8,
  "maximum_elapsed_difference_seconds": 300,
  "maximum_standardized_distance": 3,
  "realtime_weight_ppm": 500000
}
```

本人记录使用`data_origin=self_reported`及`queue_data_origin=live`，仍没有自动认证资格。参数和模型版本记录在结果中，截止不能晚于当前时钟。沿用最多16个已等时长、100个完整研究行、各源10000条修订／观测、观测32MiB和结果2MiB边界；超限明确失败，不能无声截取最近行冒充完整跨月回测。

三个数据库目录独立，输出目录与数据库分开；目录0700、文件0600，输出只写新文件，不覆盖，保留原子提交／持久确认状态。活采集写锁阻止外部打开；没有停止或复制活库、上游查询、业务取号／取消或付费调用。标准输出只有安全汇总，episode、准确时间、成对评分行和训练选择仍在本地私有结果。

## 实现依据与验收范围

[scikit-learn的时间切分说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)指出时间序列不应训练于未来再验证过去，并对跨折可比指标说明等间隔条件；[分组交叉验证说明](https://scikit-learn.org/stable/modules/cross_validation.html)要求关联样本在相应训练／验证划分中保持分组隔离。本项目是原创标准库回放：直接按每次预测的可用截止扩展训练、整体排除目标episode，处理不规则采样与首次接收，不直接套用`TimeSeriesSplit`或宣称这些规则证明真实可用性。成对区间算术是本项目实现，不归因于上述工具的算法。

专项使用真实创建的三个私有库、明确合成经历和响应，验证趋势改变等待、改善与误导变差都能保留、未来资料不影响旧预测、目标全部排除、未知和冷启动不删、条件剩余只减一次、原库不变及实际CLI私人输出。它验证软件计算链路，不能替代自然用餐数据、模型准确度、真实AI收益、生产预测记录、历史来源新鲜度或门店语义验收。

下一步先积累自然真实结果、记录真正的预测输入与输出，再运行同一时间切分的历史／实时／融合／实际AI对照，校准误差并以未来资料评估。原两预测、理想偏移、60／30秒防过号、跳号波动、用户页面、全国门店、服务器及后置业务目标继续保留。
