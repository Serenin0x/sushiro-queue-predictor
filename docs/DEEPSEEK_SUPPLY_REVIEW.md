# 外部建议复核：YYB 与正常客户端供应

2026-10-11，Codex。依据本人提供的 DeepSeek 回复、固定源码及本项目实测；外部建议不扩大软件运行、账号授权或云端凭证传输范围。

## 判断

优先验证 YYB 的指定 AppID 协议取码合理，但目前只能称“有源码实现的候选路线”，不能称“已经能够生成寿司郎接受的登录 code”。源码证明服务如何请求取码；寿司郎初始化接受、完整上下文被独立查询接受，才证明本项目接通。随后还需无人供给、原进程真实跨到期和营业日持续采集。

## 逐项纠正

| 外部回复 | 本轮复核与实施影响 |
| --- | --- |
| 开头断言可取得寿司郎接受的code，后文又说没有寿司郎案例 | 证据不足；有目标AppID取码实现不等于目标业务接受，不先切换生产 |
| 示例使用`account_id`、`appid`、`ability` | 固定[协议说明](https://github.com/525815266/YYB-Go-Enhanced/blob/2cc8f1697d1753061c491f394cc4ebb50811725a/docs/protocol-api.md)及[HTTP入口](https://github.com/525815266/YYB-Go-Enhanced/blob/2cc8f1697d1753061c491f394cc4ebb50811725a/internal/httpapi/app.go#L980)实际使用`ref`、`app_id`，不需要`ability`。缺字段400是调用错误，不能叫寿司郎拒绝 |
| 用`/api/v1/accounts/active`找账号 | 没有给出这个路径的可核出处；不按此实现，明确选择一个本人授权的账号引用 |
| 寿司郎AppID是关键未知，需要反编译 | 本项目已从正常Referer确认目标AppID并校验同应用；不增加反编译工作或公开私有上下文 |
| code外形、固定前缀或长度证明等价，取码总是毫秒级 | 外形不证明应用、账号、会话与业务接受；示例不支持固定格式和速度保证，必须实测 |
| 京东脚本存在证明已经线上验证 | 固定树确有京东脚本及检查文件，但脚本、合成检查与作者描述不等于本项目网络验收，不借其他品牌认证寿司郎 |
| Linux缺直接导码实现，所以不具备执行条件 | 正常客户端可在内部登录并产生查询上下文，外部不必调用`wx.login`。本项目电脑微信正常上下文三店独立GET已成功；Linux支持及自动更新仍需另验，保留备用路线 |
| 协议方式不需环境检测，扫码一次可永久无人 | 会话、取码和业务都有失效／拒绝边界，源码本身存在刷新失败及重扫路径；不能承诺永不需本人认证 |
| 手机号／SIM线下核验决定本轮可行性 | 回复没有给出一手证据；当前只读公共叫号，个人取号后置。不把未证实线下规则当403根因或测试取号权限 |

正确的无真实账号参数示例：

```json
{"ref":"1","app_id":"wx0000000000000000"}
```

实际值来自本机正常核对。成功响应还包含账号资料；未来适配器只能读取`result.code`，不输出OpenID、昵称、code或原始错误正文。

2026-10-11实际本机运行补正：固定0.2.28的`writeJSON`还在外层封装`code/msg/data`，完整HTTP JSON路径应为`data.result.code`；先核对HTTP成功及外层数值`code=0`。此前`result.code`是内部结果字段，不是完整HTTP根路径。健康响应也为`data.ok`，初次就绪脚本按根`ok`判断false已保留并另存纠正，服务实际返回200／`code=0`／`data.ok=true`。源码入口和本机响应共同支持这一点，不据此宣称目标取码已通过。

## 本轮正常客户端实验

实际保存并重开核对 SAPI 唯一解密域名、详情过滤器后，使用新增`detail`＋指定3030门店接收，操作一次官方页刷新。接收器先就绪、独立40秒关闭守护正常收尾；实际`surge_window_timeout`、窗口内候选0、旧revision1保持，无独立来源GET或初始化POST。

官方页由01:36更新至01:41，证明页面操作生效；凌晨队列空值不认证源新鲜度。后续摘要有200条recent、142条active，但无寿司郎域名；系统代理与增强模式开启，内存过滤器重开确认不使用过滤器，一次公共DNS与摘要地址计数也无当前SAPI匹配。可能涉及既有／未命名连接、代理排除、其他传输路径或记录时机，**唯一原因尚未确定**。这次是流量可见性失败，没有观察到SAPI401／403，不再相同条件重复刷新。

原CRM过滤器与名单恢复、三开关关闭，Surge和官方小程序保持打开。新入口为本地开发源码，69项受影响检查通过，未发布／部署；不是永久无人供应器。
