# 终态匿名采集窗口质量

候选 0.2.0rc36 新增 `remote-window-quality`，为24/72小时验收提供完整窗口的只读证据。它与普通按店最近1000条报告、短时信号分析分开：核对任务之后的全部已提交结果，不把预算用完、失败或短时成功说成原定全天结束。实际安装与回放、公开及CI结果见 [PROJECT_HANDOVER.md](PROJECT_HANDOVER.md)。

## 使用与存储边界

```sh
sushiwait remote-window-quality --db /private/runtime/queue/remote.sqlite3 \
  --task-file /private/runtime/queue/task.json \
  --as-of 2026-10-07T14:10:00Z --max-gap 360
```

路径是操作者自己的私有0700目录/0600文件，报告本身也应留在私有环境，不把真实门店数据提交到公开仓库。明确 `as-of` 必须不早于保存的终态检查点。`max-gap` 为1–7200秒诊断阈值，默认360；300秒背景采集或60/30秒临近用餐应各选择适用阈值，工具不自动认证允许频率或预测误差。

只接受保存的 completed/failed、无在途检查点。CLI在打开数据库前先拒绝未完成任务，因此不读取正在运行的长采集库。只读库沿用父目录共享锁、文件身份和权限校验，不读私人计划、不创建查询客户端、不读取微信凭证、不联网、不重启任务。复制到不同路径或不同文件身份的库不能借用原任务；目前没有迁移证据工具。

核对schema2任务/原始截止与预算、同一库身份、窗口起点之后连续行ID、运行ID、指定门店、成功标志、每个合法记录、累计HTTP数及完整SHA256结果链。窗口之前的旧行不纳入。最多原成对预算+2行，逐行读取，不只抽查尾部；额外行、修改、缺行、未来或倒退的请求时刻均拒绝。读取期间的数据库指纹/data_version和任务原文再次核对，异常返回固定错误码，不输出路径、原响应或个人计划。

## 报告含义

报告给出原计划时长、分析时段、终止原因、是否达到deadline检查点、成功/失败/未知槽位与已记录请求数。预算完成不等于截止完成；未知尝试消耗仍保持，无法归到具体门店或核对HTTP数时显示unknown。

各店保留实际第一次/最后一次请求、起始跨度、相邻请求间隔，以及成功请求在窗口开头、结尾和内部的缺口。分析区间从任务创建到min(as-of,deadline)，较早预算结束后未覆盖的尾部不会消失；没有成功记录时，两个边界均显示分析时长，不能将缺失当作零。内部缺口数量与边界各自输出，不将同一空窗相加为两份覆盖率。

按Asia/Shanghai请求开始日期和小时分别统计；每日附该日首次请求时刻的既有日期特征，年度/公告未知状态沿用 [CALENDAR.md](CALENDAR.md)，这不是历史生产特征日志。请求时间重建不是本机首次接收时间，也不是源更新时间；不能直接拿该报告消除预测回测中的可用性限制。

五类展示数组和原始数量分别统计“不同的相邻观测次数”，保留顺序/重复/后缀的比较语义，不输出具体号码或数量。失败、不同run和超过阈值的长缺口断开比较；它不是叫号、过号人数或速度。原始数量单位unknown。已开始的一对允许在原deadline之后完成，报告另记这类完成次数，不把晚响应算成新的截止后查询。

`ok=true` 只表示报告成功且内部结果链一致；`checkpoint_chain_verified=true` 不认证上游真实性、进程当前存活、全天源刷新或训练资格。`continuous_collection_verified=false`、`source_freshness=unknown`、`response_store_identity_verified=false`、`verified_training_labels=0`、`eta_available=false` 保持。完整验收还须结合实际进程终态、原起止与缺口、源语义/近时对照，以及生产主机持续运行，见 [V0_2_ACCEPTANCE.md](V0_2_ACCEPTANCE.md)。

## 已有软件与回放证据

22项专项覆盖跨北京时间午夜、三店分开、成功/两类失败、内部与尾部缺口、预算提前结束、丢失在途结果、不同run、晚完成、坏链/额外行/超长标识/复制库/读取时变更、只读与未完成任务提前拒绝。传输均合成并禁止socket/凭证读取，不能充当真实24小时数据。

本轮源码先对已有rc31终态短窗口离线回放，核对3行/此前6GET、预算结束、约89.967秒请求跨度、1个重启边界与尾部阈值超出；原库/任务/计划字节保持，新增请求0。这不是正在运行的24小时库；最终39模块安装包的同一回放已通过，并对正在运行的24小时任务验证了库打开之前拒绝；完整证据见E0253。
