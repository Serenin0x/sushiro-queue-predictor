## 用户在购买页面的操作

1. 本人登录已有云账号，完成供应商要求的正常账号流程。进入供应商官方轻量云活动／购买页，先查看本人可享年付套餐和库存。
2. 选择地域、2核2GB或有合适促销的4GB规格、Ubuntu24.04系统镜像及套餐自带磁盘；不要额外选择GPU、付费应用镜像或预装大模型服务。
3. 配置公网网络和可承受的带宽／流量上限，查看预计费用明细后本人完成购买；确认套餐已包含的磁盘／流量；额外磁盘、超额流量、快照可能另计费，未确认费用前不自动下单。[控制台创建Linux实例](https://help.aliyun.com/zh/ecs/getting-started/create-and-manage-an-ecs-instance-by-using-the-ecs-console/)、[公网计费](https://help.aliyun.com/zh/ecs/public-bandwidth/)
4. 登录方式优先正常SSH密钥，本机保存私钥。初期管理访问使用受限SSH入口，统计服务仍只绑定回环，通过自己的SSH通道查看；暂时不需要对公众开放数据库或购买域名。
5. 购买后确认实例运行、系统／规格／磁盘和公网地址，建立正常本机SSH配置。账号身份验证与付费确认由本人完成；项目不要求把密码、私钥或云账号凭据粘贴到聊天。
6. 先约定试验期限和预算，结束后依据已保留数据和备份决定继续／变更计费，不能只关统计网页就认为云资源停止计费。

已有熟悉供应商时不必为本项目换账号；可用相同试验配置，按实际控制台字段操作。本文件记录当次官方价格线索，不能承诺本人账号资格、库存或未来续费价。

## 项目接入主机后的工作

1. 在指定主机用固定匿名来源少量查询验证DNS／TLS／返回协议，不读微信凭证；禁止把之前托管Linux6次GET成功当本主机成绩。
2. 部署固定版本镜像、私有持久卷、受限运行用户及只读统计出口，配置状态、日志、磁盘监控和备份空间。真实数据不放公共GitHub。
3. 接入[营业时间声明与全天方案](ALL_DAY_COLLECTION_DESIGN.md)。用户已允许默认周一至周五11:00–22:00、周末和节假日10:30–22:00，单店规则以后覆盖；必须标为user_assumed，逐GET核对窗口。本地rc56已接CLI，完整1522项、仓库外安装与无网络Linux营业边界／次日接续已通过；使用新的compose.business-hours.yaml和独立数据卷部署，不能原样启动历史24小时轮询当营业自动化。
4. 先3–12店、明确时间和请求预算，验证开店开始／闭店停止／重启不重复／异常暂停、24／72小时缺口和实际备份恢复。
5. 按日期归档和完整质量摘要连接简单浅色月历、当天汇总及单店曲线，逐步扩大门店。全国频率、正式公开访问和生产容量另验；未取得完整事件时只展示可观测指标。

租服务器可以解除个人电脑休眠的依赖，不能自动补出营业信息、完整叫号事件或预测真值，也不能代替我们的每日控制器和故障处理实现。接入路线、已有试验和正式运行边界分别见[Linux部署](LINUX_DEPLOYMENT.md)、[云端来源检查](CLOUD_SOURCE_CHECK.md)、[多日计划](MULTI_DAY_COLLECTION.md)、[完整交接](PROJECT_HANDOVER.md)。
