# DeepSeek 公共情景权重接入

rc47 实现官方固定地址的研究适配器，将公共门店趋势交给 DeepSeek 建议情景权重，再交回已有区间分布融合组件。现在没有配置真实密钥，没有付费调用、供应商有效率或延迟实测；实际等待时间仍未校准，认证结果0、`eta_available=false`。测试中明确注入的合成答复不会标成供应商实际输出。整体模型与候选生成分别见[模型设计](REALTIME_PREDICTION_MODEL.md)和[分布融合](DISTRIBUTION_FUSION.md)。

## 请求和答复

固定使用 `https://api.deepseek.com/chat/completions`、`deepseek-flash`、关闭思考、非流式JSON、温度0和显式输出token上限。TLS正常核验服务器，无代理环境读取、重定向、工具执行或自动重试。模式选择是当前低成本短答复试验设置，不是已验证最优推理模式。请求只有已有白名单公共摘要、情景ID和日期，不包含候选支持点、私人号码、取号时间、身份或精确到店计划。

模型只返回 `weights_ppm/feature_ids/reason_code` 三项。摘要、版本、生成和失效时间由本地绑定，模型不能改写；权重严格整数、非负、和为1,000,000，引用须对应已知非空特征。只接受单条完整正常结束答复，截断、工具、错误模型、额外字段、重复JSON键、NaN、空内容和无证据会回退。消失展示号码不解释为入座、过号或实际服务率，源新鲜度、数量单位和门店身份保持unknown。

请求前核当前队列证据；返回后再核时间、同输入和预算。已过期或读取历史不会读取密钥或发请求。可选 `current_request` 回调能在新观测出现时拒绝整个旧结果，包括旧先验，但还没有实现在线原子发布；不能因此把研究文件称为实时上线预测。

## 有限预算与跨中断记账

操作方在独立0700私有目录放0600 `budget.json`，固定有效期最多3天、最多1000请求，并设置请求数、累计保留token和保留费用估算上限。每次调用先用该次最大输入和输出额度，按调用方给定的价格上界、不预支缓存折扣，原子保存并同步到磁盘，再发送POST。使用同一目录的进程持有独占非等待锁；其他进程回退，不会重复占用或查询。预算内容与每份记录绑定，运行中不允许改动来重置旧额度。

`deepseek-call-N.json` 是占用记录，`deepseek-result-N.json` 是实际usage与已验证权重。没有原始响应、请求文本或密钥。中断、响应丢失、解析失败仍保留整次占用，不退款、不自动重试、不把未知费用当零。恢复同一目录保持原期限与总预算；账本缺号、格式损坏、预算改动或无法确认磁盘同步都会停用模型建议，保留本地先验。操作方不能删除账本后称作原任务恢复。

费用单位是百万分之一元人民币，配置里的单价单位为“百万token对应的百万分之一元”。它们是操作方提供的估算上界，**不是供应商账单认证或绝对金额保证**。本地以请求UTF-8字节加4096作为保守输入检查，不能精确证明供应商tokenizer的计费数；实际usage超预留时记录超限并停止后续调用。实际输入、总输出、缓存命中/未命中与思考token均检查，未知usage继续占用全额。当前没有自动价格发现、账户余额校验或价格变更监控。

完整请求使用1–30秒套接字超时和读截止，返回后的单调时钟再检查；系统DNS解析可能不受套接字超时约束，因此没有宣称严格的进程级墙钟上限。响应上限32KiB，建议内容上限16KiB，所有错误只给固定类别，不打印原始回复或私人路径。

## 同店共享与去重

同一完整公共输入、模型和提示词版本可复用仍有效的已校验权重；改变私人分布不会增加公共调用。仅HTTP读取时刻、有效期或特征整理时刻改变，而真实观测版本、最后查询时刻和数值未改变时，不再发第二次请求，也不会给旧答复重写时间来假装是新的建议；本次使用先验并标明重复观测。

账本包含提示词版本和模型版本。真实观测内容变化可以在预算内使用下一槽位。当前只是每个显式账本内的去重，不是跨服务器全局缓存；后续在线控制器需要固定一次决策输入、共享每店公共建议及原子发布。HTTP的读取时钟不等于新的上游资料，统计页面的5秒轮询不能直接触发付费模型。

## 使用入口

默认入口只生成私有先验研究结果，不读取预算或密钥、不联网：

```sh
sushiwait deepseek-fusion --input plan.private.json --output output/result.private.json
```

输入计划沿用[分布融合契约](DISTRIBUTION_FUSION.md)。输出目录和计划目录均0700、文件0600，输出必须是新文件；实际请求时输出与预算目录必须分开。真实调用需要显式增加三个选项：`--budget-file ledger/budget.json --api-key-file key.private.json --allow-paid-request`。配置前必须按当时官方价格与允许预算填写；本轮没有使用该付费选项访问官方。

专用密钥文件只有 `schema_version:1`、`purpose:"deepseek_official"` 和 `api_key` 三项，不接受微信鉴权或其他供应商配置包，不自动读取环境、系统凭证或网关文件。通过正常私有配置提供，不能提交GitHub或贴入聊天。

预算示例结构（时间与金额必须由操作方替换；以下单价只演示计算，不代表当时官方报价）：

```json
{
  "schema_version": 1,
  "provider": "deepseek_official",
  "model": "deepseek-flash",
  "created_at": "2026-10-08T00:00:00Z",
  "deadline_at": "2026-10-08T01:00:00Z",
  "max_calls": 1,
  "max_reserved_tokens": 20512,
  "max_reserved_cost_microunits": 44096,
  "max_prompt_tokens": 20000,
  "max_output_tokens": 512,
  "input_rate_microunits_per_million": 2000000,
  "output_rate_microunits_per_million": 8000000,
  "price_basis": "caller_supplied_ceiling_not_verified",
  "timeout_seconds": 10
}
```

标准输出只给保存/持久化、建议参与、缓存、回退、供应商请求及未校准状态。完整私有结果另外保留usage及按配置估算费用。输出路径预检避免对已存在文件付费查询；若付费请求后发布失败，账本独立保留，不重新发POST，输出的committed状态须单独处理。
