# 关电脑后的云端采集对照

2026-10-12 E0470。当前目标是服务器独立采集，以关电脑后仍能采集为迁移标准。用户选择今晚关机、明天核对；已有云端查询、自动更新及进程恢复证据不能代替真实电脑离线期间的新记录。

## 对照安排

服务器已保存一次基线，并启用三个有限状态记录：当天闭店后、次日开店前、次日开采后。它们读取既有任务和已保存的统计副本，不增加寿司郎查询、不控制会话或重启采集、不保存查询上下文正文。每项只在预定小窗口内执行一次，错过不补跑；完整运行信息保留在所有者的私有交接中。

原三家门店、十分钟采样、营业时间及既定有限试验预算不变。已创建任务不表示未来执行成功，状态记录也不能自行证明电脑已经断网。

## 如何判定

1. 记录用户真实关机或断网的起止时间，离线期间应覆盖营业采集时段，最好至少二十分钟、包含两个新采样节点。
2. 核对各店的原响应时间、实际成功记录与服务器持久副本；使用门店数据时间，不使用网页读取时间。
3. 若离线跨到次日开店，确认开店后的新记录与自然更新，无需重新打开小程序。闭店后与开店前的状态可用于核对夜间是否停止采集。
4. 保留失败和缺口，不补造节点或用旧记录刷新时间。满足真实迁移标准后完成该目标；长时间稳定性和服务器整机重启属于另行记录的范围。

只有关管理网页、计划今晚关机、运行进程存在或定时任务已启用，均不能单独证明电脑离线后继续采集。当前未宣称该项完成；未执行的未来时间条件按实际结果追加[完整项目交接](PROJECT_HANDOVER.md)。
