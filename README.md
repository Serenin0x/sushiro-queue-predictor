# SushiWait

面向中国大陆寿司郎门店的开源项目，目标是结合小程序实时排队信息与历史规律，预测叫号时间、规划到店和取号时机，并降低过号风险。本项目为独立项目。

## 模型功能

当前处于设计与数据接入验证准备阶段，**尚无可运行预测模型或实时监控服务**。已完成需求整理、参考项目研究和开发路线设计。本节随实际交付更新。

## 技术手段

计划先验证大陆门店的只读实时请求与数据刷新延迟，再积累历史和真实叫号结果。候选方案为 Python / FastAPI、PostgreSQL、Redis 后台调度、统计与分位数预测；大语言模型用于提取有来源的外部事件并辅助解释。技术栈尚未实现或冻结。

前端在实时数据准备充分后开发；Logo 和动态图文介绍安排在后期。

## 版本说明

当前为 **v0.1.0 初始设计基线**，不是可用产品发布。下一阶段验证实时数据字段、鉴权、刷新延迟和 60 / 30 秒采样能力。
