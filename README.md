# SushiWait

面向中国大陆寿司郎门店的开源项目，目标是结合小程序实时排队信息与历史规律，预测叫号时间、规划到店和取号时机，并降低过号风险。本项目为独立项目。

## 模型功能

已有可运行的只读数据验证工具：门店目录筛选、单店快照、有界采样、SQLite 本地存储、合成数据离线回放、字段缺失与展示号码变化检查。

**预测模型尚未实现，真实门店字段与刷新速度尚未验收。** 本节随实际交付更新。

## 技术手段

当前使用 Python 3.11+ 标准库、固定 HTTPS 只读请求和 SQLite；区分缺失、空值、零值，保留分队列展示数组和来源时间状态。运行与接入步骤见 [数据验证手册](docs/DATA_ACCESS.md)。

后续候选方案为 FastAPI、PostgreSQL、Redis 后台调度、统计与分位数预测；大语言模型用于提取有来源的外部事件并辅助解释。这些后续组件尚未实现。

前端在实时数据准备充分后开发；Logo 和动态图文介绍安排在后期。

## 版本说明

当前为 **v0.2.0.dev0 接入验证工具开发版**，不是可用预测产品。大陆目录接口已做真实无凭证测试，返回 401；仍需核对官方小程序查询授权，再验证实际字段和 60 / 30 秒刷新能力。
